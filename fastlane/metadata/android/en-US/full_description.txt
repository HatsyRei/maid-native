<p>A lightweight, Material 3 native Android client for your own OpenAI-compatible server, such as llama.cpp, Ollama or LM Studio. No account, no telemetry, no ads: a ~2 MB app and your own endpoint.</p>

<p><b>Chat</b></p>
<ul>
<li>Streaming replies with Markdown rendering, parsed incrementally so long answers stay smooth.</li>
<li>Branching conversations: edit, revise or regenerate any message and step between versions.</li>
<li>Image, audio and text attachments, offered when the model supports them.</li>
<li>Collapsible reasoning output, and a Thinking toggle for models that support it.</li>
<li>Generation stats under each reply: tokens, time and tokens per second.</li>
</ul>

<p><b>Endpoints</b></p>
<ul>
<li>Scan your local network to find a llama.cpp or other OpenAI-compatible server without typing an IP.</li>
<li>Endpoint presets and a model picker for switching in a couple of taps.</li>
<li>API keys are encrypted at rest with an Android Keystore key and kept out of cloud backups.</li>
<li>Sampling and penalty controls, each off by default so your server's settings still apply.</li>
</ul>

<p><b>Tools</b></p>
<ul>
<li>Opt-in tools the model can call: date and time, a dice roller, fetching a web page, and a sandboxed JavaScript runner.</li>
<li>Linked text files the model can read, search and edit for the rest of a conversation.</li>
<li>Remote MCP (Model Context Protocol) servers over Streamable HTTP.</li>
<li>Every tool can be Off, Ask or Allow, and Ask calls wait for your approval.</li>
</ul>

<p><b>And</b></p>
<ul>
<li>History is stored on the device, so browsing past chats works offline.</li>
<li>Chat import and export in JSON.</li>
<li>AMOLED black theme with a custom accent colour, composer artwork, and custom names and profile pictures.</li>
<li>English and Simplified Chinese interface.</li>
</ul>
